# ライブ共有とLINE速報のセットアップ

## 1. 観戦ページ（QR共有）— LINEの設定なしで使える

同伴者は**QRを読むだけ**で途中経過を見られる。読み取り専用で、10秒ごとに自動更新される。
LINEの通数を一切消費しないので、**「毎ホール速報を見せる」目的はこちらで満たす**。

必要な設定は1つだけ。

```toml
APP_BASE_URL = "https://xxxx.streamlit.app"
```

未設定でも `RAKUTEN_REFERER` があればそれを流用する。どちらも無ければ画面で入力できる。

観戦URLは `<APP_BASE_URL>/?live=<8桁のID>` で、IDは **プレー日＋コース名から機械的に決まる**
（`live_id_for`）。同じ日・同じコースなら再起動しても同じURLになるので、
ラウンド中にアプリを開き直してもQRを配り直す必要がない。

## 2. LINE速報 — 設定は任意

### 前提（2026-08 時点）

- **LINE Notify は2025年3月末で終了**。代替は Messaging API（LINE公式アカウント）。
- 無料枠（コミュニケーションプラン）は**月200通**。
- **グループ送信は「送信対象の人数」でカウントされる**。4人グループへ1送信＝4通。
- 出典: https://developers.line.biz/ja/docs/messaging-api/pricing/

### 消費の目安（4人グループの場合）

| 配信頻度 | 1ラウンド | 月200通で |
|---|---|---|
| 毎ホール | 72通 | 2.7ラウンド |
| 3ホールごと＋最終 | 24通 | 8ラウンド |
| ハーフごと＋最終（既定） | 8通 | 25ラウンド |

### 手順

1. https://manager.line.biz/ で LINE公式アカウントを作る
2. アカウント設定で **「グループ・複数人トークへの参加を許可する」** をONにする
   （OFFのままだとBotをグループに入れられない）
3. https://developers.line.biz/ で該当チャネルを開き、
   **Messaging API設定 → チャネルアクセストークン（長期）** を発行してコピー
4. **送信先ID（グループID）の取得**。ここだけ一手間かかる。
   - LINE Developers の Messaging API設定で **Webhook URL** に
     https://webhook.site で発行した使い捨てURLを一時的に設定し、Webhookの利用をONにする
   - Botをゴルフのグループに招待し、グループ内で何か発言する
   - webhook.site に届いたJSONの `source.groupId`（`C` で始まる文字列）を控える
   - 控えたらWebhook URLは元に戻す（空でよい）
   - ※ 1対1で自分にだけ送るなら、LINE Developers の「あなたのユーザーID」がそのまま使える
5. secrets に設定する

```toml
LINE_CHANNEL_ACCESS_TOKEN = "（長期のチャネルアクセストークン）"
LINE_TO = "Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"   # グループID または ユーザーID
```

### アプリ側の操作

「📝 スコア入力」→ **📣 ライブ共有・LINE速報**

- 「同伴者に途中経過を見せる（ライブ共有をON）」にチェック
- 観戦ページのQRが出るので、同伴者に読んでもらう
- 配信頻度を選ぶ（既定は「ハーフごと＋最終」）。選んだ頻度での**消費見込み通数が画面に出る**
- 1ホール全員分の入力が終わるたびに観戦ページが更新され、節目のホールだけLINEへ送られる
- 手動の「🔄 観戦ページをいま更新する」「📣 いまの状況をLINEに送る」も使える
- スコア保存時に最終結果がLINEへ送られる（配信ONかつ「送らない」以外のとき）

同じホールを2回送らないよう、送信済みのホールはセッション内で記録している。
